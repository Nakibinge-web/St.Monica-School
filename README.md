# Evergreen Academy - School Website

A complete, fully-connected website for Evergreen Academy, a Ugandan primary school.

## Website Structure

The website consists of 7 interconnected pages:

### 1. **Home (index.html)**
   - Hero section with call-to-action
   - Statistics cards (500+ students, 45 teachers, 12 awards)
   - Headteacher welcome message
   - News & Events bento grid

### 2. **About Us (about.html)**
   - School history (founded 1995)
   - School anthem
   - Facilities showcase (Library, Science Labs, Sports Complex)

### 3. **Academics (academics.html)**
   - Academic performance overview
   - Grading system (Distinction, Merit, Credit, Pass)
   - Assessment schedule
   - Academic support programs

### 4. **Curriculum (curriculum.html)**
   - Core subjects: Mathematics, English, Science, Social Studies
   - Religious education program
   - UNEB standards alignment

### 5. **Co-curricular (cocurricular.html)**
   - Athletics & Sports programs
   - Music, Dance & Drama
   - Student clubs (Scouting, Red Cross, Environment Club)

### 6. **Gallery (gallery.html)**
   - Masonry-style photo grid
   - Category filters (Campus Life, Academics, Sports, Events)
   - Hover effects showing image captions

### 7. **Contact Us (contact.html)**
   - Contact form (Name, Email, Subject, Message)
   - School contact information
   - Location map
   - Newsletter subscription

## Design Features

- **Design System**: "Profound Heritage" - Corporate Modern aesthetic
- **Color Palette**: 
  - Primary: Deep navy blue (#1e2a4a, #081534)
  - Accent: Bright red (#d93633, #b51a1e)
  - Surfaces: White and light gray backgrounds
- **Typography**: Montserrat font throughout
- **Framework**: Tailwind CSS
- **Icons**: Material Symbols Outlined
- **Responsive**: Mobile-first design with desktop optimization

## Navigation

Every page has a consistent top navigation bar with links to all sections:
- Home
- About Us
- Academics
- Curriculum
- Co-curricular
- Gallery
- Contact Us

The active page is highlighted with an underline in the navigation.

## Footer

Every page includes a comprehensive footer with:
- Quick links
- Contact information
- Newsletter signup
- Social media placeholders
- Copyright notice

## How to Use

1. Open `index.html` in a web browser to start
2. Navigate through the site using the top navigation menu
3. All links are properly connected - click any menu item to visit that page
4. The "Join Us" button throughout the site links to the Contact page

## Browser Compatibility

The website uses modern CSS and works best in:
- Chrome/Edge (latest)
- Firefox (latest)
- Safari (latest)

## No Dependencies Required

The website loads all resources from CDNs:
- Tailwind CSS
- Google Fonts (Montserrat)
- Material Icons

Just open the HTML files in a browser - no build process or installation needed!
